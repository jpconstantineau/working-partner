Natural Planning: brainstorming

Work in progress. This is the collection's first experimental skill, not a released or independently validated training programme.

When you know what you want a project to achieve but keep returning to the first possible solution, make room for alternatives before deciding.

Where it fits

David Allen's Getting Things Done (GTD) Natural Planning Model considers purpose and principles, outcome vision, brainstorming, organizing, and next actions. This page covers brainstorming only. You do not need to run all stages for every project.

Try it with a working partner

  1. Start with the outcome. State what the project is intended to achieve and the constraints already known.
  2. Capture possibilities. Offer your own ideas and ask your AI partner for genuinely different approaches. Keep generation separate from judging each suggestion.
  3. Look for missing angles. Consider other people, resources or approaches that could contribute. Mark missing facts as research questions.
  4. Stop when the pool is useful. Group and compare ideas when helpful, preserving which are unassessed, selected or rejected for now.

You remain responsible for choices and commitments. Ideas are possibilities, not verified facts or permission to act. If you already have enough options, skip more brainstorming. If the problem is missing evidence, investigate instead.

A fictional example

A small workshop needs a low-cost venue. A library room, shared studio and outdoor shelter provide different starting options. Keep questions about price, accessibility and availability visible for later checking. A plausible venue suggestion is not evidence that it is available.
