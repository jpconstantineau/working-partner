# Working Partner

Skills and methods for humans and AI to think, plan, and work together.

## Skills

Start with **working-partner**. It selects a work class, then a use case and a relevant method:

- [Working Partner](skills/working-partner/SKILL.md): interactive entry point.
- [Productivity](skills/productivity/SKILL.md): choose a productivity use case.
- [Brainstorming](skills/productivity-brainstorming/SKILL.md): choose a brainstorming method.
- [GTD Natural Planning brainstorming](skills/productivity-brainstorming-gtd-npm/SKILL.md): develop project options before organizing or selecting them.

## Learn

[Learn Natural Planning brainstorming](https://jpconstantineau.github.io/working-partner/gtd-npm-brainstorm.html), or browse its [HTML source](docs/gtd-npm-brainstorm.html).

## Install from a checkout

List the available skills:

```sh
npx skills@latest add . --list
```

Install the routing path and GTD method, choosing your agent and installation scope when prompted:

```sh
npx skills@latest add . --skill working-partner productivity productivity-brainstorming productivity-brainstorming-gtd-npm
```

You can also select individual skills.
