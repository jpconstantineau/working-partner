# Working Partner

Skills and methods for humans and AI to think, plan, and work together.

## Skills

Start with **working-partner**. It selects a work class, then a use case and a relevant method. Each Natural Planning step is also a standalone entry point:

- [Working Partner](skills/working-partner/SKILL.md): interactive entry point.
- [Productivity](skills/productivity/SKILL.md): choose a productivity use case.
- [Brainstorming](skills/productivity-brainstorming/SKILL.md): choose a brainstorming method.
- [Purpose and principles](skills/productivity-purpose-gtd-npm/SKILL.md): GTD Natural Planning step.
- [Outcome vision](skills/productivity-outcomes-gtd-npm/SKILL.md): GTD Natural Planning step.
- [Brainstorming](skills/productivity-brainstorming-gtd-npm/SKILL.md): GTD Natural Planning step.
- [Organizing](skills/productivity-organizing-gtd-npm/SKILL.md): GTD Natural Planning step.
- [Next actions](skills/productivity-actions-gtd-npm/SKILL.md): GTD Natural Planning step.

## Learn

[Explore all five Natural Planning learning pages](https://jpconstantineau.github.io/working-partner/), or browse their [HTML index](docs/index.html). Start at any step and continue only when useful.

## Install from a checkout

List the available skills:

```sh
npx skills@latest add . --list
```

Install the routing path and GTD method, choosing your agent and installation scope when prompted:

```sh
npx skills@latest add . --skill working-partner productivity productivity-brainstorming productivity-brainstorming-gtd-npm
```

You can also select individual skills by their exact names above. Each works without installing its neighbours; next-step suggestions are optional.
