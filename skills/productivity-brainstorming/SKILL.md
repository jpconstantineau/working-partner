# Brainstorming

Use the existing outcome, constraints, and ideas to select a method below. Load only the method that fits the current gap.

## Method catalogue

- **GTD Natural Planning Model** → `productivity-brainstorming-gtd-npm`: capture possibilities, explore neglected angles, and leave a useful option pool ready to organize. Use when a project has too few or too-similar approaches. Skip generation when there are already enough options or the gap needs factual research.

If the selected method is unavailable, consider another suitable available method from this catalogue. If none fits, help directly. Stop generating when the option pool is useful; organizing is a possible next move, not a required additional exercise.
