# Brainstorming

Identify the question or situation, what the person hopes to explore, and the ideas and constraints already known. Select a method whose scope fits that need; brainstorming can support projects and non-project work. Load only the matching method.

## Method catalogue

- **GTD Natural Planning Model** → `productivity-brainstorming-gtd-npm`: capture possibilities, explore neglected angles, and leave a useful option pool ready to organize. Use when a project has too few or too-similar approaches. Skip generation when there are already enough options or the gap needs factual research.

If the selected method is unavailable, consider another suitable available method from this catalogue. If none fits, help directly without forcing a project-planning frame. Stop generating when the option pool is useful; organizing is a possible next move, not a required additional exercise.
