# Natural Planning: next actions

Identify currently feasible, visible actions and keep blocked future steps separate.

## Start from the user’s work

Reuse current context. Ask only for missing information that materially changes the next move; the user need not name or study the method. Enter here directly when this is the bottleneck, without rerunning earlier stages. Read [REFERENCE.md](REFERENCE.md) on first application or source uncertainty.

## Workflow

1. **Inspect the current outcome, outline and actual prerequisites. Identify which parts can move now.**
   Done when: Ready work is separated from blocked or speculative future work.
2. **Express each useful next move as a concrete activity with a recognizable result. Identify a proposed actor only when supported.**
   Done when: The action can be started without repeating the planning decision.
3. **If the gap is planning or evidence, name that activity specifically. Confirm what the user wants to do, delegate or leave as a proposal.**
   Done when: A small actionable set is distinguished from assignments and completed work.

## Branches

- Keep multiple independent ready actions when useful; do not force a serial chain or assign extra work automatically.
- When an action is blocked, record its dependency or waiting condition and identify a permitted enabling action. Mark proposed ownership separately from accepted assignment.

## Boundaries

Identifying a next action does not authorize execution, scheduling or contacting anyone. Multiple independent actions may be ready; dependent future steps stay in project support.

## Finish and optional next step

Stop when the requested output is useful. This is the final Natural Planning stage; there is no automatic sixth skill. Offer the selected action for execution under the current authority, or stop with the proposed actions. Revisit `productivity-organizing-gtd-npm` only if dependencies remain unclear, or another earlier step if its output is the real gap. If the named skill is unavailable, use another fitting available method or help directly. Never require installing the rest of the sequence. A next-step suggestion is not permission to act.
