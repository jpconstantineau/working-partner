# Natural Planning: organizing

Turn available project ideas into just enough structure to see useful next work.

## Start from the user’s work

Reuse current context. Ask only for missing information that materially changes the next move; the user need not name or study the method. Enter here directly when this is the bottleneck, without rerunning earlier stages. Read [REFERENCE.md](REFERENCE.md) on first application or source uncertainty.

## Workflow

1. **Read existing ideas and the intended outcome. Group related components without losing source or selection status.**
   Done when: A comprehensible set of themes or components exists.
2. **Identify dependencies, ordering and relative importance against the agreed purpose and outcome. Label uncertain relationships.**
   Done when: The outline distinguishes prerequisites from independent work.
3. **Separate selected components, alternatives and evidence gaps. Choose the smallest useful outline or map rather than inventing a complete schedule.**
   Done when: The user can see what could move next and what remains undecided.

## Branches

- Keep unmatched ideas and uncertain placement visible. Distinguish necessary dependencies from preferred ordering.
- If an ordering depends on an unknown fact, mark the relationship conditional and identify a fact-finding step. Stop decomposing when more detail would not change the next move.

## Boundaries

This is project planning, not the GTD inbox-organizing workflow. Avoid invented estimates, owners and deadlines; a group of ideas is not an approved plan.

## Finish and optional next step

Stop when the requested output is useful. If the user wants to continue and the next gap fits, offer `productivity-actions-gtd-npm` as the next Natural Planning step. Carry forward the accepted output, constraints and open questions; do not restart intake. Load that skill only when continuing is useful. If the named skill is unavailable, use another fitting available method or help directly. Never require installing the rest of the sequence. A next-step suggestion is not permission to act.
