# Worked example: Natural Planning: brainstorming

This is a fictional design illustration, not an observation about the user or evidence of effectiveness. Use its shape with the user's actual work; do not turn it into a lesson during execution.

**Input:** A small workshop needs a low-cost venue.

**Moves:** Capture options such as a library room, shared studio or outdoor shelter. Explore overlooked possibilities without screening each one immediately. Keep feasibility concerns visible for the later organizing step rather than prematurely ending generation.

**Output:** A varied option set ready for evaluation, with questions about availability, cost and accessibility still explicitly unverified.

**Pitfall:** Plausible-sounding venues and availability are not verified facts. Generating an option does not book it or commit the user.
